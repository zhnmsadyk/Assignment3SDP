# Assignment 3 — Bridge Pattern Implementation

## Project Overview

This repository contains an implementation of the **Bridge Design Pattern** in Java as part of Assignment 3.

The **Bridge pattern** is a structural design pattern that decouples an abstraction from its implementation so that the two can vary independently. In this project, the **Shape–Renderer** domain is implemented to demonstrate runtime flexibility through composition over inheritance.

---

## System Architecture & Structure

The project separates the abstraction hierarchy (`Shape`) from the implementation hierarchy (`Renderer`).
